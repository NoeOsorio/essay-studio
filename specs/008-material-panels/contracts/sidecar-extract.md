# Contract: sidecar `extract` request

## Wire

Rust command `sage_extract(id, task, text, reviewerProfile?)` validates `task` and writes one JSON line:

```ts
type ExtractRequest = {
  id: string; type: "extract";
  task: "citation" | "rubric";
  text: string;            // citation: at most CITATION_PREFIX_CHARS; rubric: at most ASSIGNMENT_MAX_CHARS; enforced in assertReviewRequest
  reviewerProfile?: string;
};
```

Events are the existing `started`, `token`, `complete`, `error` on `sage://event`. TS wrapper `extract({ task, text })` in `src/lib/agents/index.ts` reuses `runSidecarCommand`. Same OAuth fence, no tools, `maxTurns: 1`, 120 s. In `runner.ts` it is a fourth `case` of 006's exhaustive switch. Invalid requests raise 006's `ReviewRequestError` with `INVALID_REQUEST` or `SOURCE_TOO_LARGE`; over the cap of 11, `BUSY`.

## Prompt

Fixed system prompt per task, no persona, in `sidecar/src/extract-prompts.ts`. The text is delivered with the same fence as `renderFuentes`: labeled untrusted data, instructions inside it are ignored, serialized as JSON between explicit start and end markers. Output is one JSON object and nothing else.

```ts
// citation: omit what the text does not state. Never infer.
{ "titulo"?: string, "autores"?: { "apellidos": string, "nombres"?: string }[], "anio"?: string,
  "revista"?: string, "volumen"?: string, "numero"?: string, "paginas"?: string,
  "editorial"?: string, "doi"?: string }

// rubric
{ "criterios": { "nombre": string, "descripcion": string, "cita": string,
                 "peso_declarado"?: string, "peso_valor"?: number, "peso_unidad"?: "porcentaje" | "puntos" }[] }
// no recognizable criteria: { "sin_criterios": true }
```

## Validation in code (`sidecar/src/extract-parser.ts`, browser-safe, used by the renderer)

Canonical form: NFKC, case fold, all whitespace collapsed to one space. "Appears" means substring of the canonical text that was sent.

**Citation**
- Drop any field that does not appear. Authors: each of `apellidos` and each `nombres` token must appear; an author failing either is dropped.
- `anio` must match `^(1[5-9]|20)\d\d$` and appear.
- Keep only known keys. Code composes the APA string in `src/lib/materials/apa.ts`: et al. at 3 or more authors in the short form, `&` before the last author in the reference, `s.f.` when there is no year, initials from `nombres`. The model never writes it.

**Rubric**
- A criterion is kept only if `cita` appears in the assignment. This is what stops invented criteria.
- A weight counts only if `peso_declarado` appears inside the assignment text and `peso_valor` is a positive finite number.
- Weight mapping: stated values scale against the largest to 1 to 5, rounded, minimum 1. Criteria without a stated weight get 3. If none is stated, all get 3.
- `id` is generated by the renderer. Zero surviving criteria gives the same state as `sin_criterios`.

Malformed output is a failure, shown as retry. It is never partially applied.

## E2E stub

`sage_extract` answers deterministically so existing tests do not change meaning: a citation returns only the fields implied by markers in the text (including one fabricated year to exercise the validator), and otherwise `{}`; a rubric returns criteria quoted from the text.
