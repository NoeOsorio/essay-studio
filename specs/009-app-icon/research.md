# Research: New app icon

## Does a classic icon file remove the gray plate?

- **Decision**: Use a classic icon file generated by `tauri icon` from artwork with the macOS rounded-square shape.
- **Rationale**: Two throwaway apps were built outside the repo on Noe's Mac (macOS 27.2) and rendered through macOS's own icon service, next to the installed Essay Studio and Spotify. The installed app shows the gray plate. Both new versions show no plate and fill the same square as Spotify. This renders the icon the way the system does, but it is not a screenshot of the real Dock, which is checked in `quickstart.md`.
- **Alternatives considered**: A layered icon compiled from an Icon Composer file. It rendered the same and needs more parts, and the bundler supports it if it is ever wanted.

## Why are there two icons in the Dock?

- **Finding**: Two copies were running at the same time: `/Applications/Essay Studio.app` and `src-tauri/target/release/bundle/macos/Essay Studio.app`. Their binaries are identical.
- **Decision**: Swap the icon in both.

## Rebuild the app or swap only the icon?

- **Decision**: Swap only the icon in the installed copies.
- **Rationale**: The installed app reports version 0.3.0 while this checkout says 0.2.0, and it is not clear which working state produced it. A rebuild could change Noe's app beyond the icon. Future builds pick up the new icon from the repo.
- **Alternatives considered**: A full rebuild and reinstall, rejected for that risk.

## Artwork export

- **Finding**: Paper's export has an opaque white background, so its corners must be made transparent with the rounded-square shape before generating icons.
- **Decision**: The master artwork is the export with a rounded mask of 824 px and 185 px radius, centered on 1024.
