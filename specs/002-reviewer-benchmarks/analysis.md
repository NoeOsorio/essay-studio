# Consistency review

Each user concern maps to an observable check: evidence to source spans and
human support labels; citations to fidelity/identity/locators and APA cases;
reliability to clean/flawed contrasts, missing/error runs and uncertainty; voice
to blind anchored human ratings; updates to a shared profile registry and
captured requested/resolved model provenance.

Offline checks establish corpus/runtime wiring, not reviewer correctness. Draft
keys cannot produce semantic scores. Model promotion remains outside the approved
no-inference scope. Private-source inclusion follows explicit source privacy,
not the directory a source happens to occupy. Exact input reconstruction prevents
answer-key material from being injected into an otherwise approved case. Approval
replay is rejected through an exclusive execution claim.

Deferred coverage is explicit: printed-page fixtures and rubric-criterion
weighting are not part of this text-only pilot. A nonempty `criterioId` is counted
as unknown because the pilot supplies no criterion IDs. Real personal-source
selection and answer-key adjudication require a concrete review packet first.
