# UI contract: sentence card

- One card per sentence in Correcciones, in the criterion view and in the popover on an underline.
- The quote appears once. Each agent part shows its chip, severity and diagnosis; Usar este texto and Copiar appear only on a part with a replacement, which can only be Estilo or Citas APA.
- Ya lo resolví and No aplica act on the whole card.
- Testids: `finding-card` on the card, `finding-part` on each agent part; existing testids for actions stay on the card.
