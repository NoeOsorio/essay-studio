# prompts/

Carpeta para los prompts en Markdown de cada sabio del consejo. Noé los irá agregando aquí — un archivo por sabio (`empirista.md`, `sistemico.md`, `practico.md`, `critico.md`) más prompts compartidos (estilo, formato, voz general).

Estos archivos los lee `src/lib/agents/` en una sesión futura.
